# 地点切换与周边餐饮/外卖推荐方案

## 1. 目标

用户切换校区、手动定位或刷新附近时，系统自动聚合周边餐饮档口和外卖商家，并结合以下信号返回相关性推荐：

- 当前经纬度与距离
- 用户口味画像：辣度、预算、忌口、常出没食堂、作息
- 历史行为：收藏、点赞、加入饭局、外卖点单、发布内容
- 时段上下文：早餐、夜宵、配送速度

Demo 使用本地数据 Provider，接口和评分模型可直接替换为高德/腾讯地图或外卖开放平台。

## 2. 地点切换触发机制

| 触发方式 | 入口 | 行为 |
|---|---|---|
| 校区/学校切换 | 学校弹窗中的校区行 | 更新偏好，立即调用 `/api/nearby/discover` |
| 浏览器定位 | 页面“定位/重新定位” | 获取经纬度，5km 内自动识别最近开放校区，请求周边推荐 |
| 附近页刷新 | “重新搜索附近 / 刷新” | 使用当前位置重新获取数据和推荐 |
| 历史行为变化 | 收藏、点赞、点单、画像修改 | 推荐进入 history source，重新计算相关性 |
| 未定位降级 | 无浏览器定位 | 使用当前学校/校区坐标作为搜索中心 |

## 3. 周边数据获取

### 当前 Demo Provider

`LocalVenueProvider` 从 `content_items` 读取：

- `STALL`：校内档口，坐标继承所属食堂。
- `TAKEOUT`：外卖商家，使用商家自身坐标。

统一字段包括：名称、图片、价格、评分、坐标、标签、菜品、配送时间、营业时段。

### 真实平台接入

保留 `VenueProvider` 接口，后续可实现：

```text
AmapVenueProvider / MeituanVenueProvider / AggregatedVenueProvider
```

当前代码提供通用外部 Provider：

```text
app.nearby.external.enabled=true
app.nearby.external.url=https://your-gateway.example.com/nearby
app.nearby.external.token=...
```

外部接口请求：

```text
GET {url}?lat=30.23&lng=120.03&radiusMeters=2500
Authorization: Bearer {token}
```

返回任意一种格式：

```json
[
  {
    "id": "merchant-1",
    "type": "takeout",
    "name": "示例外卖",
    "lat": 30.231,
    "lng": 120.036,
    "price": 18,
    "rating": 4.6,
    "delivery": 22,
    "tags": ["黄焖鸡"],
    "dishes": ["黄焖鸡"]
  }
]
```

或：

```json
{"venues": ["..."]}
```

接入高德/腾讯地图时，可以把地图 POI 作为 `stall`，把外卖平台商家作为 `takeout`。地图 POI 通常只提供名称、地址、坐标、评分和分类；菜品、价格、配送时间需要外卖平台或自建商家库补全。

## 4. 推荐评分模型

每个地点输出 `0-99` 相关性分数：

```text
score =
  distanceScore   * 0.32
+ preferenceScore * 0.28
+ historyScore    * 0.20
+ qualityScore    * 0.10
+ contextScore    * 0.10
```

### distanceScore

```text
100 - distance / searchRadius * 85
```

限制在 `10-100`。默认搜索半径 2500 米。

### preferenceScore

- 价格在预算区间：加 20。
- 低于预算：加 12。
- 高于预算：按超出金额扣分。
- 命中忌口：扣 35。
- 辣度匹配：加 12。
- 命中常出没食堂：加 12。

### historyScore

- 点击过的目标 ID：100。
- 同食堂：加 25。
- 同菜品：加 20。
- 同标签：加 12。
- 历史外卖订单：额外加 35。

### qualityScore

```text
rating * 16 + min(checkins / 12, 20)
```

### contextScore

- 21:00-05:00：夜宵商家加分。
- 10:00 前：早餐商家加分。
- 外卖配送时间不超过 22 分钟：加分。
- 夜猫子用户夜间加权。

### 推荐理由

接口返回 `reasons`，例如：

```text
距你约 320m
人均 15 元在预算内
与你的历史口味/收藏相近
适合当前时段
```

前端直接展示该列表，避免使用不可解释的纯分数。

## 5. 接口设计

统一响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "timestamp": "..."
}
```

### PUT /api/me/location

请求：

```json
{
  "lat": 30.23105,
  "lng": 120.03648,
  "accuracy": 20,
  "source": "browser"
}
```

保存最近位置并返回最近学校判断。

### POST /api/nearby/discover

请求：

```json
{
  "lat": 30.23105,
  "lng": 120.03648,
  "accuracy": 20,
  "source": "browser",
  "radiusMeters": 2500,
  "limit": 16,
  "seed": "1",
  "excludeIds": ["s1", "s2"]
}
```

返回：

```json
{
  "location": {},
  "context": {
    "nearestSchoolId": "zjut-pingfeng",
    "nearestCampus": "屏峰校区",
    "shouldSwitchSchool": true
  },
  "recommendations": [],
  "venues": []
}
```

### GET /api/nearby/venues

适合纯列表场景，支持 `type=dining|takeout|all`，默认按距离排序。

### GET /api/nearby/recommendations

适合推荐场景，按相关性分数排序。
