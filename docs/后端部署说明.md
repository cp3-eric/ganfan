# 干饭搭子后端运行与部署说明

后端目录：`backend/`，技术栈为 Java 17、Spring Boot 3.4、Spring Security、JPA、Flyway、MySQL 8。开发环境默认使用 H2（MySQL 兼容模式），生产环境使用 MySQL 8。

## 1. 本地开发

### 环境要求

- JDK 17+
- Maven 3.8+
- Node.js 18+（仅前端静态服务需要）
- MySQL 8（生产或本地联调时需要）

本机便携构建环境已安装在：

```text
D:\java-build-tools\jdk-17.0.21.0.2+1
D:\java-build-tools\apache-maven-3.9.9
Maven 依赖仓库：D:\java-build-tools\m2
```

PowerShell 启动示例：

```powershell
$env:JAVA_HOME="D:\java-build-tools\jdk-17.0.21.0.2+1"
$env:PATH="$env:JAVA_HOME\bin;D:\java-build-tools\apache-maven-3.9.9\bin;$env:PATH"
cd backend
mvn -Dmaven.repo.local="D:\java-build-tools\m2" spring-boot:run --arguments=--server.port=8080,--server.address=127.0.0.1
```

若运行环境中的 `SERVER_PORT`/`PORT` 覆盖了配置，可显式增加：
`--server.port=8080 --server.address=127.0.0.1`。

### 启动后端（开发模式）

```bash
cd backend
mvn spring-boot:run
```

默认：

- API：`http://127.0.0.1:8080/api`
- 数据库：内存 H2，程序启动时自动执行 Flyway 和种子数据
- 演示账号：`demo@ganfan.local / demo123456`
- 管理员：`admin@ganfan.local / admin123456`

### 启动前端

```bash
node server.js
# 浏览器打开 http://127.0.0.1:5173
```

前端会自动连接 `http://127.0.0.1:8080/api`。也可以通过查询参数指定后端：

```text
http://127.0.0.1:5173/?api=http://127.0.0.1:8080/api
```

### 运行测试

```bash
cd backend
mvn test
```

测试使用 H2，覆盖登录、未认证、参数校验、权限、收藏、约饭、发布、评论、打招呼、入驻和演示数据重置。

## 2. MySQL 配置

创建数据库：

```sql
CREATE DATABASE ganfan
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_0900_ai_ci;
CREATE USER 'ganfan_app'@'%' IDENTIFIED BY '替换为强密码';
GRANT SELECT, INSERT, UPDATE, DELETE ON ganfan.* TO 'ganfan_app'@'%';
FLUSH PRIVILEGES;
```

数据库表由 Flyway 的 `V1__init.sql` 自动创建，不要手工删除 Flyway 历史表。

## 3. 生产环境

生产构建：

```bash
cd backend
mvn -DskipTests clean package
```

生成文件：`backend/target/ganfan-backend-1.0.0.jar`

生产环境变量：

```bash
export SPRING_PROFILES_ACTIVE=prod
export DB_URL='jdbc:mysql://127.0.0.1:3306/ganfan?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=true'
export DB_USERNAME='ganfan_app'
export DB_PASSWORD='数据库密码'
export JWT_SECRET='使用 openssl rand -base64 48 生成的新值'
export JWT_EXPIRATION_MINUTES=10080
export CORS_ORIGINS='https://your-domain.example.com'
```

Windows PowerShell 示例：

```powershell
$env:SPRING_PROFILES_ACTIVE="prod"
$env:DB_URL="jdbc:mysql://127.0.0.1:3306/ganfan?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=true"
$env:DB_USERNAME="ganfan_app"
$env:DB_PASSWORD="数据库密码"
$env:JWT_SECRET="请替换为openssl生成的Base64密钥"
$env:CORS_ORIGINS="https://your-domain.example.com"
java -jar backend\target\ganfan-backend-1.0.0.jar
```

启动后检查：

```bash
curl http://127.0.0.1:8080/api/health
```

应返回：

```json
{"code":0,"message":"ok","data":{"service":"ganfan-backend","status":"UP"},"timestamp":"..."}
```

## 4. Nginx 同源部署

推荐将前端静态文件与 `/api` 反向代理放在同一域名，这样前端生产环境自动使用相对路径 `/api`。

```nginx
server {
  listen 80;
  server_name your-domain.example.com;

  root /var/www/ganfan;
  index index.html;

  location / {
    try_files $uri $uri/ /index.html;
  }

  location /api/ {
    proxy_pass http://127.0.0.1:8080/api/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```

上传内容：

- 项目根目录中的 `index.html`
- `assets/`
- 后端运行 `backend/target/ganfan-backend-1.0.0.jar`

国内公网域名对外提供网页服务时通常需要完成 ICP 备案。Nginx 证书可使用云平台免费证书或 Let's Encrypt。

## 5. 腾讯云建议

课程演示或低流量：

- 轻量应用服务器：2核2G
- MySQL：与应用同机安装，或购买 1核1G/1核2G MySQL
- 安全组仅开放 22、80、443；不要把 3306 暴露公网
- 8080 仅本机监听即可

生产环境：

- 轻量/CVM：2核4G
- 云数据库 MySQL 8：2核2G 或 2核4G
- 对象存储 COS：后续接入用户图片
- 每日数据库备份，保留至少 7 天
- 监控 CPU、内存、磁盘、数据库连接数和 5xx

## 6. 接口概览

统一成功响应：

```json
{"code":0,"message":"ok","data":{},"timestamp":"..."}
```

统一错误响应：

```json
{"code":40001,"message":"可读错误","data":null,"timestamp":"..."}
```

参数校验错误的 `data` 为字段错误映射。

主要接口：

- `POST /api/auth/register`
- `POST /api/auth/login`
- `GET /api/auth/me`
- `GET /api/bootstrap`
- `PUT /api/profile`
- `PUT /api/me/preferences`
- `POST|DELETE /api/favorites/stalls/{id}`
- `POST|DELETE /api/favorites/posts/{id}`
- `POST|DELETE /api/meetups/{id}/join`
- `POST /api/meetups`
- `POST /api/posts`
- `POST|DELETE /api/posts/{id}/like`
- `POST /api/posts/{id}/comments`
- `POST /api/meetups/{id}/greetings`
- `POST /api/school-applications`
- `POST /api/takeouts/{id}/orders`
- `DELETE /api/me/demo-data`
- `GET /api/admin/applications`
- `PATCH /api/admin/applications/{id}`
- `GET /api/admin/users`
- `PUT /api/me/location`
- `POST /api/nearby/discover`
- `GET /api/nearby/venues`
- `GET /api/nearby/recommendations`

所有用户接口需要 `Authorization: Bearer <token>`；`/api/admin/**` 需要 ADMIN 角色。
