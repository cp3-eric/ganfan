# 答辩演示脚本（3 分钟）

> 目标：让老师记住「校区定位 → 用户画像 → 可解释推荐 → 同校区约饭 / 打卡回流」这条闭环，并确认所有按钮都是可操作的真实逻辑。

## 0. 开场（25 秒）

> “这是『干饭搭子』电脑网页版 Demo，校区定位在浙江工业大学屏峰校区，面向 18–22 岁在校大学生，
> 解决三个问题：今天吃什么、一个人吃饭孤单、不知道周边有什么好吃的。
> UI 采用最新一版：白底到浅蓝渐变 + 深青强调色，信息按清单式组织。”

## 1. 校区与定位（20 秒）

1. 指右上角「浙江工业大学 · 屏峰校区」，点「切换」：说明已内置屏峰 / 朝晖 / 莫干山，其他学校可提交入驻。
2. 点「📍 定位」：浏览器请求定位；授权后显示「已定位 · 距家和食堂约 xxx m」。
   “定位只在本机计算距离、不上传；拒绝授权也能手动选校区。”
3. 说明数据：家和食堂（1F 经济窗口 / 3F 美食街）、养贤府（美食广场）、西门夜市、图书馆 B1。

## 2. 首页：画像驱动推荐（50 秒）

1. 指右侧画像卡：“辣度、预算、忌口、常出没、作息、社交偏好共同参与推荐。”
2. 指主推卡的**三条推荐依据**：忌口（不吃香菜 → 可免香菜）、预算（15–25 元）、常出没（家和食堂，步行 190 米）。
3. 点「换一批 ↻」：“推荐顺序实时重排，数据不是写死的。”
4. 点「编辑口味画像」，把忌口加上「海鲜」或预算改成 30–40，保存：“推荐理由和匹配度马上变了。”
5. 点主推卡「收藏」，说明会同步到「我的收藏」和右上角统计。

## 3. 约饭广场：同校区匹配（50 秒）

1. 筛选「今晚」+「人均 ≤ 30」，说明筛选可组合、排序支持匹配度优先。
2. 指卡片右侧匹配度：“由画像与饭局条件计算，不是随机数。”
3. 点「加入饭局」：座位进度真实 +1，按钮变「已加入 · 退出」，「我的约饭」+1。
4. 点「打招呼」发送消息：提示“仅同校区可见”。
5. 点「发布约饭」：填写菜品 / 食堂 / 时间 → 发布后立即排在列表顶部。

## 4. 美食社区：内容与回流（35 秒）

1. 指话题条「# 食堂隐藏吃法」与打卡卡片结构（作者、食堂、图片位、正文、标签、互动）。
2. 点赞、收藏、打开评论并追加一条 → 计数与评论列表实时变化。
3. 点「发布打卡」写一句“家和 1F 酱香饼 5.5 元，早八救星”，发布后立即出现。
4. 说明：社区只展示当前校区内容，切到朝晖后屏峰帖子不可见，切回可见。

## 5. 其他学校入驻（15 秒）

1. 点底栏「学校入驻」：展示学校全称、校区、联系人、手机号、食堂数量等表单。
2. 提交后显示「待审核」，说明流程：核验学校身份 → 补充食堂/档口数据 → 开放该校区。
3. “所以这不是只给浙工大用的，任何学校都能申请加入。”

## 6. 收尾（15 秒）

1. 打开「我的收藏 / 我的约饭 / 我的记录」抽屉：“都有真实记录，并保存在 localStorage，刷新不丢。”
2. “当前是纯前端 Demo；数据层集中在 `app.js`，后续接 Java（Spring Boot）时按 README 接口清单替换即可，页面不用改。”

## 7. 常见提问的答法

- **推荐算法在哪？** `assets/app.js` 中 `stallScore()` / `meetupScore()` / `reasonsOf()`，可解释、可调权重。
- **定位怎么做的？** 浏览器 `navigator.geolocation` + `haversine()` 直线距离；正式版接高德/腾讯地图算步行距离。
- **数据存哪里？** 浏览器 `localStorage`（键 `ganfan_demo_v2`）；抽屉里有「重置演示数据」。
- **为什么没有登录？** 基础 Demo 聚焦核心闭环；登录/权限/校区审核在后续 Java 后端扩展，接口清单已列在 README。
- **UI 是否最新？** 是，样式来自最新一版 `ui/web3`（深青强调色），并补齐了可交互状态（按钮/弹窗/抽屉）。
