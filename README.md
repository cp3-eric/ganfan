# 干饭搭子 · 校园美食社交（前后端可运行 Demo）

电脑网页版（校区：**浙江工业大学 · 屏峰校区**），UI 采用白底 → 浅蓝渐变、深青强调色、清单式信息结构。
**所有按钮都有真实行为**：推荐排序、搜索、收藏、约饭加入/退出、发起饭局、打招呼、点赞、评论、
发布打卡、话题筛选、画像编辑、榜单切换、我的收藏/约饭/记录抽屉、演示数据重置、校区切换、
获取定位、学校入驻申请。

> 前端为 HTML + CSS + 原生 JS；后端为 `backend/` 中的 Java Spring Boot + MySQL/Flyway + JWT。
> 用户数据、饭局、帖子、收藏、消息和入驻申请均持久化到后端；精确浏览器定位仍只保存在本机。
> 部署、环境变量、MySQL 与 Nginx 配置见 `docs/后端部署说明.md`。

## 一、怎么运行

### 1. 启动后端

```bash
cd backend
mvn spring-boot:run
```

开发模式默认使用内存 H2，自动建表并写入演示数据。API 地址为 `http://127.0.0.1:8080/api`。

### 2. 启动前端

**方式 A（推荐）**：双击 `启动.bat`，会检查后端 JAR 与 Node.js，然后打开
`http://127.0.0.1:5173`。

**方式 B（命令行）**：

```bash
node server.js
# 浏览器访问 http://127.0.0.1:5173
```

> 端口被占用时可先设置环境变量：`set PORT=5180 && node server.js`

### 3. 默认账号

- 用户：`demo@ganfan.local / demo123456`
- 管理员：`admin@ganfan.local / admin123456`

生产部署必须修改默认密码与 JWT 密钥。

## 三、校区、定位与学校入驻

### 1. 校区数据（浙江工业大学屏峰校区）
- 学校：**浙江工业大学 · 屏峰校区**，杭州市西湖区留和路 288 号（邮编 310023）。
- 坐标：校园中心约 `30.2311, 120.0365`（OpenStreetMap 校园范围中心）。
- 食堂（演示整理）：
  - **家和食堂**：1F 经济窗口与早餐档，2F 自助取餐，3F 美食街（黄焖鸡、油泼面、水果捞等）。
  - **养贤府**：美食广场，麻辣香锅、煎包、排骨饭、炒面等，是屏峰最常被提到的食堂。
  - **西门夜市**：留和路西门，21:00 后最热闹。
  - **图书馆 B1 咖啡**：桂花拿铁、美式等自习续命饮品。
- 档口价格、评分、打卡量均为**演示数据**，不是官方数据。

### 2. 定位服务（真实浏览器 API）
- 入口：右上「📍 定位」、学校弹窗「用定位推荐校区」。
- 浏览器请求 `navigator.geolocation` 权限；拿到坐标后用 Haversine 计算与校区、食堂的直线距离。
- 首页/约饭地图显示「已定位 · 距家和食堂约 210m」；距其他开放校区 5km 内会自动切换。
- **隐私**：坐标只保存在本机 `localStorage`，不上传；拒绝授权可手动选校区，功能不受影响。
- 注意：定位要求安全上下文（`http://127.0.0.1` 或 `https://`）；直接双击 `file://` 时可能被浏览器禁用，属正常限制。

### 3. 同校区交流
- 首页推荐、约饭广场、美食社区、搜索结果、我的消息都只展示**当前选中校区**的内容。
- 发布饭局/打卡会自动写入当前校区；切换校区后其他校区内容不可见（数据保留，切回可见）。
- 「同校区」筛选与「打招呼」提示均按校区校验，避免跨校区要约。

### 4. 其他学校如何加入（入驻入口）
- 入口：首页底部快捷栏「学校入驻」；学校弹窗「+ 我的学校也要入驻」。
- 表单字段：学校全称、校区、城市、联系人、手机号、食堂数量、邮箱/公众号、补充说明。
- 提交后写入本机 `state.applications`，状态为「待审核」，可在学校弹窗查看最近申请。
- 流程：提交资料 → 核验学校身份 → 补充食堂/档口数据 → 开放该校区内容与约饭。
- 当前内置：浙工大屏峰（已入驻）、浙工大朝晖（已入驻，食堂数据待补）、浙工大莫干山（筹备中）。

## 五、数据与算法（可讲解）

- **画像**：辣度、预算区间、忌口、常出没食堂、作息、社交偏好。
- **档口匹配度**：预算命中 +8、忌口无冲突 +8、常出没 +5、辣度匹配 +4、步行距离修正等，截断到 60–99。
- **饭局匹配度**：基础分 + 预算匹配 + 忌口校验 + 同校区 + 夜宵与作息匹配。
- **推荐依据**：由画像实时生成（不是写死文案）；改画像后首页依据与约饭匹配度会一起变化。
- **持久化**：`localStorage` 键名为 `ganfan_demo_v2`。

## 七、后端与接口

后端代码位于 `backend/`，已实现：

- JWT 登录/注册、普通用户与管理员角色权限。
- 用户画像、校区偏好、收藏、加入饭局、打招呼、点赞、评论、打卡、饭局、入驻申请与演示数据重置。
- MySQL/H2 持久化、Flyway 建表、演示账号与目录种子数据。
- Bean Validation 参数校验、统一响应格式和全局异常处理。
- 管理员入驻审核与用户查询接口。

| 功能 | 接口 |
|---|---|
| 登录 / 注册 / 当前用户 | `POST /api/auth/login`、`POST /api/auth/register`、`GET /api/auth/me` |
| 目录与用户状态 | `GET /api/bootstrap` |
| 画像读写 | `PUT /api/profile` |
| 校区偏好 | `PUT /api/me/preferences` |
| 收藏档口 / 帖子 | `POST/DELETE /api/favorites/stalls/{id}`、`POST/DELETE /api/favorites/posts/{id}` |
| 加入 / 退出饭局 | `POST/DELETE /api/meetups/{id}/join` |
| 发布饭局 | `POST /api/meetups` |
| 发布打卡 / 点赞 / 评论 | `POST /api/posts`、`POST/DELETE /api/posts/{id}/like`、`POST /api/posts/{id}/comments` |
| 打招呼 | `POST /api/meetups/{id}/greetings` |
| 学校入驻申请 | `POST /api/school-applications` |
| 外卖演示点单 | `POST /api/takeouts/{id}/orders` |
| 重置演示数据 | `DELETE /api/me/demo-data` |
| 管理员审核 | `GET /api/admin/applications`、`PATCH /api/admin/applications/{id}`、`GET /api/admin/users` |

请求与响应格式、部署配置见 `docs/后端部署说明.md`。

## 十一、附近吃饭与随机选店

- **独立一级页面**：顶部导航新增「附近吃饭」（`#/nearby`），与首页、约饭广场、美食社区同级；首页也有一条深青色「附近吃饭，纠结就交给随机」横幅，直接进入。
- **定位后自动搜索**：点「📍 定位」授权后自动跳到附近页，把校内 10 家档口与附近 6 家外卖合并成一张按匹配度排序的清单，顶部给出「先吃这家」建议（预算、忌口、常去食堂、距离/配送时间）。
- **随机选店**：附近页有整块决策区，点「🎲 随机帮我选一家」会在合并池里抽一家，显示抽中卡片与「就吃这家 / 再抽一次」；首页横幅也可直接抽。
- **筛选与排序**：清单支持「全部 / 校内 / 外卖」和「按匹配 / 按距离」切换；每家可打开详情（校内看推荐依据，外卖看配送时间与演示点单）。
- 外卖商家、配送时长为课程演示的合成数据；当前 Demo 使用本地餐饮 Provider，生产可替换为高德/腾讯地图和外卖开放平台。
- 地点切换会触发 `/api/nearby/discover`，结合距离、口味画像、预算和历史行为生成推荐；详细方案见 `docs/地点推荐方案.md`。内置自检 41 项，含附近合并、排序、随机、去重与页面渲染。
